# 🧑‍🔬 Major Research Groups & Ecosystems

This section maps influential Efficient-ML ecosystems across academia, industry, startups, and open-source communities.

Each public group profile will summarize:

- institution / company / project;
- principal investigators and core contributors;
- major Efficient-ML directions;
- representative 2024–present papers;
- official repositories and runtimes;
- technical lineage and collaborations;
- why the group is worth following.

## Coverage families

| Family | Examples of what is tracked |
|---|---|
| **Academic systems labs** | serving, compilers, distributed systems, architecture, efficient AI |
| **Industrial research** | NVIDIA, Microsoft, Google/DeepMind, Meta, Alibaba, ByteDance, etc. |
| **Runtime ecosystems** | vLLM, SGLang, FlashInfer, LMCache, llama.cpp, MLC, TensorRT-LLM |
| **Hardware ecosystems** | GPU/NPU/PIM/CXL/wafer-scale/edge accelerators |
| **Physical AI** | VLA/WAM, embodied runtime, robot inference, edge-cloud deployment |

The public index is generated only from evidence-backed group entries; discovery-only internal notes are not exported.
