# 🏛️ Venue & Source Map

A systematic venue/source index for Efficient ML and AI Infrastructure.

## Core venue families

| Family | Representative venues |
|---|---|
| **Systems** | OSDI, SOSP, NSDI, EuroSys, SoCC, USENIX ATC, FAST |
| **Architecture** | ISCA, MICRO, HPCA, ASPLOS, FPGA, ISSCC, VLSI Symposium |
| **ML / AI** | NeurIPS, ICML, ICLR, MLSys, AAAI, IJCAI, COLM |
| **Vision / Multimodal** | CVPR, ICCV, ECCV, ACM MM |
| **NLP** | ACL, EMNLP |
| **Data / Web / Network** | SIGMOD, VLDB/PVLDB, KDD, The Web Conference, SIGCOMM |
| **Physical AI / Robotics** | RSS, CoRL, ICRA, IROS |

Coverage is tracked at paper/session level rather than only marking that a conference homepage was visited.

## Status semantics

- **SEARCHED** — a route was queried or visited.
- **COVERED** — the required systematic pass was completed for that round.
- **SATURATED** — the required zero-new confirmation criteria were met.

A venue is never considered saturated solely because it has been scanned once.
